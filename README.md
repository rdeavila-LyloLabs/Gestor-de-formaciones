# Gestor de Formaciones - Corporate Training App

Aplicación Web (SPA) para la gestión de planes de formación corporativos, integrada con Google Sheets.

## 🚀 Características
*   **Dashboard** con KPIs y Gráficos en tiempo real.
*   **Directorio** de empleados con búsqueda instantánea.
*   **Matriz Automática**: Cálculo de formaciones basado en Cargo.
*   **Asignación Manual**: Capacidad de asignar cursos individuales a empleados específicos.
*   **Diagnóstico**: Herramienta integrada para verificar conexión con Google Sheets.

## 🛠️ Tecnologías
*   **Backend**: Google Apps Script (.gs)
*   **Frontend**: HTML5, Tailwind CSS, Vanilla JS.
*   **Base de Datos**: Google Sheets.

## 📂 Estructura del Proyecto
*   `Code.gs`: Lógica del servidor (Backend).
*   `Index.html`: Interfaz de usuario (Frontend).

## 📦 Instalación
1.  Crear un nuevo proyecto en [Google Apps Script](https://script.google.com/).
2.  Copiar el contenido de `Code.gs` e `Index.html`.
3.  Configurar el `SPREADSHEET_ID` en `Code.gs`.
4.  Implementar como aplicación web.
